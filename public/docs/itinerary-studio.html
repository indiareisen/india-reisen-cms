How Import Works

Three ways to get an itinerary in

Best effort · no setup

Auto-fetch (link)

Tries a direct browser fetch, then a couple of public CORS-proxy fallbacks if that's blocked. When it works, it runs a simple pattern match for "Day 1, Day 2…" — no AI involved, so quality varies by page.

Best quality · needs Claude

Ask Claude, paste JSON

Paste a link to Claude in chat. It fetches the page properly and reads it — no CORS limit, since the request isn't coming from a browser — and hands back structured JSON: itinerary, highlights, weather, field notes. Paste that into "Paste JSON" here.

Most reliable · your own backend

Run the extraction server

A small included Node server does the same fetch-then-Claude step automatically, so the "Try auto-fetch" button in the Import panel calls it directly instead of you copy-pasting. Needs Node.js and your own Anthropic API key.

Why not always auto-fetch? Browsers deliberately block a page from reading another website's raw content (CORS) — it's a security feature, not a bug. A backend server has no such restriction, which is why that path is the reliable one.
